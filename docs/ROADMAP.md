# Research roadmap — demo first, production only after grant and review

## Phase 0 — public prototype (this repository)
- Separate public repository, no LICENSE.
- Synthetic one-unit order match, no real execution, CLI demo.
- Repeatable fixture and negative tests.

## Phase 1 — hackathons and pre-grant demo
- Read-only NaFT research receipt adapter + provenance verification.
- Mock order book UI, asset search and quote timeline.
- Test multi-currency assumptions, stale price and data discrepancies.
- Simulated listing freeze when a supporting research package becomes stale.
- Gather user feedback and objective benchmark measurements.

## Phase 2 — IPA MITOU Advanced spring application
- Reproducible research evidence; unique technology claims backed by comparisons.
- Architecture diagrams, research questions, risks and milestones.
- Grant-ready large implementation plan, budget and evaluation methodology.

## Phase 3 — only if funded and legally reviewed
- Independent legal and registry/rights assessments.
- Security review, consent, attestation, operational data governance.
- Consider real integrations only after necessary permissions and security assurance.

The phase plan does not imply funding approval, timing guarantees, credit issuance, or production readiness.
